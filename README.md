# 📋 Sistema de Cadastro de Clientes

[![Streamlit App](https://static.streamlit.io/badges/streamlit_badge_black_white.svg)](https://SEU-APP.streamlit.app)

## 📝 Descrição

Um sistema completo de cadastro de clientes desenvolvido com **Streamlit** e **MySQL**, oferecendo uma interface intuitiva para gerenciar informações de clientes com funcionalidades de CRUD (Criar, Ler, Atualizar, Deletar) e um dashboard analítico.

### 🎯 Funcionalidades

- ✅ **Cadastro de Clientes** - Formulário completo com validação
- 👥 **Listagem de Clientes** - Visualize todos os cadastros em uma tabela interativa
- 🗑️ **Deleção de Clientes** - Remova registros de forma segura
- 📊 **Dashboard Analítico** - Métricas e gráficos sobre os cadastros
- 🔒 **Prevenção de Duplicatas** - Validação de email único
- 📱 **Responsivo** - Funciona em dispositivos móveis e desktop

### 🛠️ Tecnologias Utilizadas

- **Python 3.8+** - Linguagem principal
- **Streamlit** - Framework para criação da interface web
- **MySQL** - Banco de dados relacional
- **Pandas** - Manipulação e análise de dados
- **Streamlit Secrets** - Gerenciamento seguro de credenciais
