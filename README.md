# 📋 User Registration Portal

[![Streamlit App](https://static.streamlit.io/badges/streamlit_badge_black_white.svg)](https://client-wizard-3000.streamlit.app/)

## 🚀 Features

- ✅ **User Registration** - Simple and secure sign-up form
- ☁️ **Supabase Integration** - Cloud PostgreSQL database connection
- 📱 **Responsive UI** - Works perfectly on desktop and mobile devices
- 🔒 **Smart Validation** - Email uniqueness constraint and error handling
- 🚀 **One-Click Deploy** - Ready for Streamlit Cloud

## 🛠️ Tech Stack

- **Python 3.8+**
- **Streamlit 1.28+**
- **Supabase (PostgreSQL)**

## 🚀 Quick Start

```bash
git clone [https://github.com/seu-usuario/seu-repositorio.git](https://github.com/seu-usuario/seu-repositorio.git)
cd seu-repositorio
pip install -r requirements.txt
streamlit run app.py
